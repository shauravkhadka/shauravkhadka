# Profile design system

**Concept:** Research observatory meets working engineering portfolio.

Visual language: grid-based surfaces, orbital research system, restrained signal animation, compact technical diagrams, and content that points to real work.

## Colors

- Midnight dark `#071422` / `#0E2338`
- Daylight ice `#F2F8FC` / `#DBEDF3`
- Human-centred research accent teal `#45E0CD` (dark), `#0A8F90` (light)
- Systems engineering blue `#6F9CFA` (dark), `#486AD7` (light)
- Evaluation accent amber `#FFC777`

## Optional modes

- `README.md`: original animated desktop orbit, static mobile art and a reduced-motion-friendly static PNG fallback.
- `README-STATIC.md`: if you prefer no animated motion, copy its content over README.md.

## Editorial guardrails

1. Keep hero title and current institutional affiliation accurate.
2. Add a project card only when a useful codebase, case study or actual demo exists.
3. Separate early research directions and technical reports from peer-reviewed publications.
4. Never copy or fake contribution streaks or awards; GitHub reports activity independently.
5. Avoid turning skills into an exhaustive logo wall.

The original images can be regenerated or redesigned using the optional generator reference (not included here); all assets in the ZIP are original graphics rather than copied third-party banners.
