# Publish this GitHub profile

1. Unzip `Shaurav-GitHub-Signature-Profile.zip`.
2. Open https://github.com/shauravkhadka/shauravkhadka.
3. Upload `README.md` together with the `assets/` directory, preserving all filenames and folder structure.
4. Commit and use GitHub Preview; inspect light mode, dark mode, desktop and mobile.
5. If you want no animation, replace the contents of README.md with the text in `README-STATIC.md`.
6. The `PREVIEW-*.png` and `DESIGN-NOTES.md` files are documentation and do not need to be committed to your profile repository.

## Constraints

- GitHub profile READMEs don't support arbitrary JavaScript. Animation is supplied as self-hosted GIF; mobile receives static artwork.
- Tech logo rows use `skillicons.dev` and `img.shields.io`; these are the only third-party visual service dependencies.
- There are no commit-frequency graphs, invented awards, profile view counters, or fabricated role/availability badges.
- Publications are explicitly described as non-peer-reviewed and research work-in-progress is labelled.
- Prior GitHub connector write attempt was denied by integration permissions. This package has not been pushed to your live profile.
